# Спецификация: Lector (ЯзИС, ЛР 8 + ЛР 9, вариант 1)

## Цель

Одна система вместо двух лабораторных. Она синтезирует речь по английским научным
статьям по computer science (ЛР 8) и распознаёт голосовые команды, которыми эта
система управляется (ЛР 9).

## Обязательные функции

- **ЛР 8:**
  - ввод текста; вставка из буфера обмена; чтение выделения в другом приложении
    (html-страница, через расширение Chrome);
  - воспроизведение;
  - выбор голоса, темпа, громкости и других параметров чтения.
- **ЛР 9:**
  - пользовательский список операций;
  - автоматическая реакция на речь с уведомлением о происходящем;
  - выбор естественного языка.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Синтез | Kokoro-82M локально (PyTorch CPU) | лучшее качество среди моделей для CPU; таймстемпы слов; Groq TTS на бесплатном тарифе даёт 3,6K токенов в день |
| Распознавание | Groq Whisper large-v3-turbo + Parakeet-TDT 0.6B v3 int8 локально | облако точнее, локальная модель без сети и без квоты; во время чтения только локальная |
| Детектор речи | Silero VAD в браузере | на сервер уходят только фразы; Web Speech API в Chromium на Linux не работает |
| Нормализатор | переписчик спанов с картой смещений | подсветка произносимого слова в исходном тексте, даже когда `O(n^2)` превращается в пять слов |
| Команды | шаблоны → RapidFuzz → LLM со строгой JSON-схемой | прозрачный алгоритм; LLM не может выдумать действие |
| Хранилище | SQLite (WAL); встроенный каталог и лексикон — в коде | один пользователь; миграции данных не нужны |
| «Другое приложение» | расширение Chrome MV3 (offscreen-плеер) | нет CORS и запросов Local Network Access |
| Эхо от динамиков | push-to-talk по умолчанию; вычитание эха; приглушение; только локальный распознаватель во время чтения | AEC Chrome на Linux не вычитает звук Web Audio |

## Границы

- **Всегда:**
  - `make test` и `make lint` зелёные перед сдачей;
  - интерфейс на английском;
  - числа в README — из реальных прогонов `make loopback`.
- **Спросить сначала:** новая runtime-зависимость; отправка пользовательского текста
  стороннему сервису, кроме Groq.
- **Никогда:**
  - коммитить `.env` и ключи;
  - скачивать модели во время запроса (бэкенд работает с `HF_HUB_OFFLINE=1`);
  - пропускать или удалять падающие тесты.

## Критерии готовности

1. `make up` с нуля доводит систему до состояния `healthy`, UI открывается на :8100.
2. Встроенная статья читается; предложение и слово подсвечиваются синхронно.
3. Голос, скорость, тон, громкость, паузы и правила чтения меняются и слышны со
   следующего предложения.
4. Импорт arXiv (HTML LaTeXML) и PDF даёт оглавление и формулы.
5. `make loopback`: не меньше 95 % верно распознанных чистых команд, не больше 5 %
   ложных срабатываний на прозе и собственном голосе.
6. Команды отключаются и редактируются, свои команды-макросы работают; язык команд
   переключается.
7. Расширение читает выделенный текст на странице Википедии.
