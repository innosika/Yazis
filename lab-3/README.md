# Автоматическое реферирование документов (sentence extraction + OSTIS)

Лабораторная работа по дисциплине «Языки интеллектуальных систем», **вариант 1**:
языки текстов — русский и английский, методика — *sentence extraction* + OSTIS,
предметные области — научные статьи по computer science и сочинения по литературе.

Система строит для документа реферат двух видов:

1. **классический реферат** — 10 наиболее значимых предложений исходного текста,
   выводимых в том порядке, в котором они идут в документе (текст не переписывается);
2. **реферат в виде списка ключевых слов** — 15 терминов с наибольшим весом TF-IDF;

и выгружает результат как **фрагмент семантической сети в SC-коде** (нотация SCs).

## Быстрый старт

```bash
python3 run.py            # запускает локальный сервер и открывает браузер
```

Адрес по умолчанию — <http://127.0.0.1:8765/>. Внешние библиотеки не нужны:
достаточно **Python 3.10+** и любого современного браузера.

```bash
python3 run.py --port 9000 --no-browser   # другой порт, без автозапуска браузера
```

## Что реализовано

### Обязательная часть

* коллекция из 10 документов сопоставимого объёма (≈ 20 000 символов, 5 ru + 5 en);
* удаление чисел, слов чужого алфавита и стоп-слов (362 русских и 305 английских
  словоформ в списках);
* стемминг: собственные реализации алгоритмов Snowball для русского языка
  и Porter2 для английского (без внешних зависимостей);
* веса терминов по формуле методических указаний
  `w(t,D) = 0,5 · (1 + tf(t,D)/tf_max(D)) · log(|DB|/df(t))`;
* веса предложений `W(Si) = Posd(Si) · Posp(Si) · Score(Si)`;
* генерация реферата: 10 предложений с наибольшим весом в порядке следования в тексте;
* активная ссылка на исходный документ, сохранение в файл и печать;
* простой интерфейс со встроенной справкой (вкладка 7) и подсказками.

### Дополнительно

* **карта текста** — исходный документ с подсветкой по весу предложений, мини-карта
  документа и разбор веса любого предложения (Posd, Posp, Score и вклад каждого слова);
* **реферирование страницы по ссылке** — система скачивает веб-страницу, убирает
  разметку, меню и сноски и собирает текст по абзацам (только стандартная библиотека,
  без внешних парсеров; локальные адреса блокируются);
* **управление составом коллекции** — любой новый текст (вставленный, открытый из файла
  или загруженный по ссылке) сразу сохраняется в коллекцию: |DB| увеличивается, df(t)
  и веса терминов пересчитываются для всех документов; повторное добавление того же
  текста копию не создаёт, свои документы помечаются значком и удаляются из интерфейса;
* **статистика коллекции** — разбор отсева слов (стоп-слова, короткие, чужой алфавит,
  числа), ранго-частотное распределение с оценкой показателя закона Ципфа и гистограмма
  документных частот df(t);
* **навигация «слово → предложения»** — щелчок по ключевому слову подсвечивает в тексте
  все предложения с этим термином, показывает, сколько из них попало в реферат,
  и позволяет переходить между вхождениями (на состояние можно дать ссылку вида
  `#heat:term=нейрон`);
* **три альтернативных метода отбора** — TextRank (PageRank по графу предложений),
  гибрид «позиция + TextRank», базовая эвристика Lead-N — и метрики их сопоставления
  (ROUGE-1/2/L, коэффициент Жаккара, время работы);
* **диагностика позиционного перекоса** формулы: показывает, сколько содержательных
  предложений отсеяно множителями Posd/Posp, и позволяет менять степени α, β
  (при α = 0 влияние позиции в документе отключается);
* **MMR** — подавление повторов при отборе предложений;
* **склейка близких основ** — исправление известных расхождений стеммера
  («систем» / «сист», «роман» / «рома»), отключаемая в интерфейсе;
* **интерактивная визуализация семантической сети** двух уровней: отдельного документа
  и всей коллекции (документы, общие ключевые слова, дуги тематической близости);
* **матрица близости документов** коллекции (косинусная мера по векторам TF-IDF);
* **пакетная обработка** всей коллекции с таблицей показателей и выгрузкой в CSV;
* реферирование **собственного текста** (вставка в диалог или открытие файла `.txt`);
* выгрузка в TXT, HTML, JSON, CSV и SCs (отдельно — SC-код всей коллекции);
  печать открытой вкладки из браузера.

### Удобство работы

Строка текущего документа со всеми его характеристиками видна на любой вкладке; параметры
разделены на основные и исследовательские, отклонение от значений методички отмечается
значком и сбрасывается одной кнопкой. Есть поиск по коллекции, подсказка для первого
запуска, индикатор выполнения запроса, понятные пустые состояния и подсказки у метрик,
диалоги с проверкой ввода и сообщениями об ошибках, постоянные ссылки на состояние
интерфейса (`#compare`, `#graph:collection`, `#heat:term=…`) и горячие клавиши:
<kbd>1</kbd>…<kbd>8</kbd> — вкладки, <kbd>↑</kbd>/<kbd>↓</kbd> — соседний документ,
<kbd>/</kbd> — поиск, <kbd>Esc</kbd> — снять выделение термина, <kbd>?</kbd> — список клавиш.

## Консольный интерфейс

```bash
python3 -m summarizer.cli --list                          # состав коллекции
python3 -m summarizer.cli --doc ru_cs_ai                  # реферат в консоль
python3 -m summarizer.cli --doc en_lit_hamlet --format html -o out.html
python3 -m summarizer.cli --file статья.txt --sentences 7 --keywords 20
python3 -m summarizer.cli --url https://ru.wikipedia.org/wiki/Алгоритм
python3 -m summarizer.cli --url <адрес> --add-to-collection       # сохранить в коллекцию
python3 -m summarizer.cli --batch --csv data/output/collection_report.csv
```

Полезные ключи: `--method tfidf|textrank|hybrid|lead`, `--alpha`, `--beta`
(степени позиционных функций), `--mmr`, `--no-conflate`.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Всего 50 проверок. Тестируются стеммеры, сегментация с сокращениями и инициалами,
фильтрация токенов, формулы весов, позиционные функции, метрики, корректность SC-кода,
сквозной сценарий реферирования (в том числе то, что предложения реферата берутся из
текста без изменений и выводятся в исходном порядке), разбор HTML-страницы, защита от
загрузки локальных адресов, добавление и удаление документов коллекции и статистика.
Сеть в тестах не используется: разбор HTML проверяется на локальном образце страницы.

## Обновление коллекции

```bash
python3 tools/fetch_collection.py
```

Скрипт скачивает статьи через MediaWiki API, очищает их от разметки и служебных
разделов и приводит к сопоставимому объёму (≈ 10 страниц А4). Список источников
задаётся константой `SOURCES` в начале файла.

## Форматы выгрузки

| Формат | Содержимое |
|--------|------------|
| `.txt`  | текстовый отчёт: оба реферата и показатели |
| `.html` | оформленный отчёт с таблицами весов, пригодный для печати |
| `.json` | полный результат: веса всех предложений и терминов, метрики, SC-код |
| `.csv`  | таблица весов всех предложений документа (Posd, Posp, Score, W) |
| `.scs`  | фрагмент семантической сети в SC-коде для загрузки в базу знаний OSTIS |

Отдельная кнопка «SC-код всей коллекции» выгружает общую семантическую сеть: документы,
их предметные области и общие ключевые слова, представленные одним sc-узлом на понятие.
