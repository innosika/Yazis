    Реферирование страницы по ссылке
    
    
    
      
    
        
        
        
    Система скачает страницу, уберёт разметку, меню и сноски,
          соберёт текст по абзацам и добавит документ в коллекцию. Подходят статьи
          Wikipedia, Habr, новостные и научные публикации; страницы, где текст
          подгружается скриптами, не поддерживаются.
