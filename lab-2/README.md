# Лабораторная работа 2 — «Автоматическое распознавание языка текста»

**Вариант 1:** языки — русский, английский; формат документов — HTML; методы — N-грамм, алфавитный, нейросетевой.

Веб-приложение: backend на Python (FastAPI + PyTorch), frontend на React. Всё запускается в Docker.

## Быстрый старт

```bash
cp .env.example .env      # и укажите GROQ_API_KEY (нужен только для голосовой диктовки)
make up                   # сборка и запуск
```

- Интерфейс: <http://localhost:3000>
- API (Swagger): <http://localhost:8000/api/docs>

Другие команды: `make help`.

| Команда | Что делает |
|---|---|
| `make up` / `make down` / `make restart` | запуск / остановка / перезапуск контейнеров |
| `make logs` | логи сервисов |
| `make test` | pytest внутри контейнера бэкенда |
| `make corpus` | пересобрать тренировочный корпус и тестовую коллекцию из Wikipedia |
| `make hard-cases` | перегенерировать сложные документы коллекции |
| `make retrain` | сбросить кэш нейросети и переобучить |
| `make report` | сохранить результаты прогона коллекции в `reports/` (JSON, CSV, HTML) |
| `make clean` | удалить контейнеры, образы и тома проекта |

## Возможности

1. **Документ** — вставка текста или загрузка HTML (drag-and-drop); ответ трёх методов, уверенность, время, детали (профиль N-грамм, доли алфавитов, softmax).
2. **Коллекция** — тестовая коллекция из 30 HTML-документов (по 15 на язык, ≈1 страница A4 каждый, Wikipedia). Прогон даёт: результат по каждому документу (с активной ссылкой на документ), точность и среднее время каждого метода, матрицы ошибок. Сохранение в JSON/CSV, HTML-отчёт, печать. Можно добавлять свои HTML-файлы.
3. **Голос** *(доп. фича 1)* — запись с микрофона → Groq Whisper (`whisper-large-v3`, язык не указывается) → текст → распознавание языка тремя методами; ответ Whisper показывается для сравнения.
4. **Кривая обучения** *(доп. фича 2)* — точность каждого метода на случайных фрагментах длиной 5…1280 символов: сколько текста нужно методу для уверенного ответа.
5. **Справка** — инструкция, описание методов, FAQ; на элементах интерфейса — всплывающие подсказки «?».

## Структура

```
backend/app/
  main.py            FastAPI: маршруты /api/*; при старте — загрузка корпуса и обучение методов
  config.py          константы (N=5, профиль 300, параметры сети), пути, ключи
  preprocessing.py   HTML → текст (BeautifulSoup), нормализация
  corpus.py          тренировочный корпус, тестовая коллекция, загрузки пользователя
  methods/ngram.py   метод N-грамм (Cavnar–Trenkle, out-of-place)
  methods/alphabet.py алфавитный метод
  methods/neural.py  нейросетевой метод (MLP на hashing-признаках, PyTorch)
  evaluation.py      распознавание, прогон коллекции, сводная статистика, кривая обучения
  reports.py         экспорт CSV / печатный HTML-отчёт
  voice.py           Groq Whisper
backend/scripts/build_corpus.py   сборка корпуса из Wikipedia
backend/scripts/build_hard_cases.py  генерация сложных документов (транслит, гомоглифы, смешанные тексты и т.д.)
backend/tests/                    pytest

```

## Алгоритм (кратко)

1. **Предобработка.** Удаление тегов, `<script>`, `<style>`; нижний регистр; остаются только буквы и пробелы.
2. **Поисковый образ языка (ПОЯ)** строится по корпусу один раз при старте:
   - *N-грамм:* все подстроки длиной 1–5 слов с маркерами `_слово_`; топ-300 по частоте — профиль.
   - *Алфавитный:* распределение частот букв алфавита языка.
   - *Нейросетевой:* корпус нарезается на фрагменты 40–600 символов → hashing-вектор символьных 1–3-грамм (4096) → MLP 4096→128→2, Adam, 12 эпох.
3. **Поисковый образ документа** строится теми же правилами.
4. **Сравнение:** out-of-place-расстояние (N-грамм); 0.7·доля букв алфавита + 0.3·косинус частот (алфавитный); softmax (сеть).
5. **Решение:** язык с наилучшей метрикой; итоговый ответ — голосование трёх методов.

## Результаты тестирования

Коллекция: 30 обычных документов (статьи Wikipedia, ≈3 КБ текста) и 12 сложных (`hard_*`, генерируются скриптом `backend/scripts/build_hard_cases.py`).

| Метод | Обычные | Сложные | Всего | Среднее время на документ |
|---|---|---|---|---|
| N-грамм | 100 % (30/30) | 67 % (8/12) | 90.5 % | ≈ 6–7 мс |
| Алфавитный | 100 % (30/30) | 67 % (8/12) | 90.5 % | ≈ 0.7 мс |
| Нейросетевой | 100 % (30/30) | 67 % (8/12) | 90.5 % | ≈ 5 мс |

Сложные документы и поведение методов:

| Документ | Истина | Результат | Почему |
|---|---|---|---|
| Русский текст в транслите | ru | все методы → en | кириллицы нет вовсе; N-граммы транслита (`zh`, `kh`, `ya`) не входят в профиль русского |
| Русский текст с латинскими гомоглифами | ru | верно, но уверенность низкая (0.13–0.5) | половина букв латинские, решают оставшиеся кириллические |
| Английский с кириллическими гомоглифами | en | верно, уверенность снижена | зеркальный случай |
| Русская статья с IT-терминами | ru | все методы → en | английских букв больше, чем русских |
| Английское эссе с русскими названиями | en | верно, алфавитный на грани (0.15) | кириллические вставки ≈ 30 % |
| Короткое сообщение с брендами | ru | верно, N-грамм почти наугад (0.09) | 88 символов, половина — латинские бренды |
| Короткое чат-сообщение | en | верно | — |
| Английский SMS-сленг | en | верно, N-грамм 0.76 | нестандартные слова, но буквы английские |
| Дореформенная орфография | ru | верно, N-грамм 0.72 | ѣ, і, ъ отсутствуют в профиле |
| Python-код с русскими комментариями | ru | все методы → en | ключевых слов и идентификаторов больше, чем русских слов |
| Английский, записанный кириллицей | en | все методы → ru | алфавит побеждает: ни один метод не «слышит» английскую лексику |
| Английская статья с русскими пословицами | en | верно | русских цитат ≈ 40 %, недостаточно для ошибки |

Обучение при старте: N-грамм ≈ 0.3 с, алфавитный ≈ 0.01 с, нейросеть ≈ 2 с (далее веса берутся из кэша).

Для пары русский/английский алфавиты не пересекаются, поэтому на документах объёмом в страницу все методы безошибочны, а различия проявляются:
- на очень коротких фрагментах (10–20 символов) — кривая обучения показывает единичные ошибки у всех методов (например, английские заимствования внутри русского текста);
- в быстродействии — алфавитный метод примерно в 10 раз быстрее N-грамм;
- на смешанных текстах (пример «смешанный» на вкладке «Документ») методы расходятся, и итог определяется голосованием.

## Примечание по голосовой диктовке

Запись с микрофона в браузере требует `localhost` или HTTPS. Транскрипция выполняется моделью `whisper-large-v3` через Groq API без указания языка; ключ хранится в `.env` и в репозиторий не попадает.
